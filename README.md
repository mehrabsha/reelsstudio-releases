# ReelsStudio releases

Installers and the auto-update feed for ReelsStudio. This repo holds binaries only, no source code.

- **Download:** grab `ReelsStudio-Setup-<version>.exe` from the [latest release](../../releases/latest).
- The app updates itself from here and downloads its Whisper model on first launch.
- `model-large-v3-turbo-q5_0` is a mirror of the Whisper model (MIT license), not an app release.
